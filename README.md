# Learning Materials / 学习笔记

我的学习笔记仓库，按科目和章节组织。

## 目录结构

```
学习笔记/
├── 高等数学/
│   ├── 第01章-函数与极限/       ← 函数基础、极限与连续
│   ├── 第02章-导数与微分/       ← 求导公式、链式法则、隐函数
│   ├── 第03章-中值定理与导数应用/ ← 洛必达、单调性、极值、拐点
│   ├── 第04章-不定积分/         ← 凑微分、换元、分部积分
│   └── 第05章-定积分及其应用/    ← N-L 公式、旋转体、弧长
├── Python/
│   └── 基础语法/               ← 面向对象：类/对象/封装/继承/多态
├── 网页/                       ← HTML、CSS、JavaScript（待补充）
├── 英语/                       ← 词汇语法、听说读写（待补充）
├── 人工智能/                   ← 机器学习、深度学习（待补充）
└── 自学杂项/                   ← 书评、工具技巧、碎片知识
```

## 命名规则

```
科目/
└── 章节/模块/
    └── YYYYMMDD-具体主题.md
```

- **科目名**：用中文，一目了然
- **日期前缀**：`YYYYMMDD` 格式，保证按时间排序
- **连字符分隔**：不用空格，兼容命令行操作

## 笔记模板

每篇笔记包含以下板块：

- **课堂要点 / 核心概念** — 本节讲了什么
- **关键公式** — 公式单独列出，方便复习
- **例题** — 看完知识点立刻看例子
- **疑问** — 当时没懂的，课后解决
- **自查清单** — 学完对照打勾

## 使用方式

支持任何 Markdown 编辑器打开，推荐：

- **Obsidian** — 双链笔记，知识图谱
- **VS Code** — 配合 Markdown Preview Enhanced 插件
- **Typora** — 所见即所得，LaTeX 公式实时渲染

cd ~/桌面/学习笔记
