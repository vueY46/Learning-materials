# 第06章：定积分及其应用

>  定积分是整个微积分的巅峰。前面所有的极限、求导、不定积分，最终都服务于它。它的核心问题是：「曲边图形的面积怎么算？」

---

## 6.1 定积分的定义

### 从面积问题出发

要求 $y = f(x)$ 在 $[a, b]$ 上与 $x$ 轴围成的面积。曲线不是直线，直接算不了。

**思路（微元法）：**
1. 把 $[a, b]$ 分成 $n$ 个小区间
2. 每个小段上用矩形面积近似代替曲边面积
3. 让 $n \to \infty$（每个小段宽度 $\to 0$），取极限

### 数学定义

$$\int_a^b f(x)\,\mathrm{d}x = \lim_{\lambda \to 0} \sum_{i=1}^{n} f(\xi_i) \Delta x_i$$

其中 $\lambda = \max\{\Delta x_i\}$，$\xi_i$ 是每个小区间内任取的一点。

>  这就是**黎曼积分**的定义。本质：无数个窄矩形的面积之和的极限。

### 几何意义

- $f(x) \geq 0$ 时：定积分 = 曲线下方、$x$ 轴上方的面积
- $f(x) \leq 0$ 时：定积分 = **负面积**
- $f(x)$ 有正有负：定积分 = 正面积 − 负面积（即代数和）

---

## 6.2 定积分的性质

| 性质 | 公式 |
|:---|:---|
| 线性 | $\int_a^b [f \pm g] = \int_a^b f \pm \int_a^b g$ |
| 数乘 | $\int_a^b kf = k\int_a^b f$ |
| 区间可加 | $\int_a^b f = \int_a^c f + \int_c^b f$ |
| 上下限交换 | $\int_a^b f = -\int_b^a f$ |
| 保序性 | 若 $f(x) \leq g(x)$，则 $\int_a^b f \leq \int_a^b g$ |
| 估值定理 | $m(b-a) \leq \int_a^b f \leq M(b-a)$（$m$ 最小值，$M$ 最大值） |

---

## 6.3 微积分基本定理

这是整门课最重要的定理，它把微分和积分联系在了一起。

### 变上限积分函数

$$\Phi(x) = \int_a^x f(t)\,\mathrm{d}t$$

**关键性质：** $\Phi'(x) = f(x)$

即：变上限积分的导数 = 被积函数在上限的值。

>  这意味着：积分是微分的逆运算，和我们之前学的不定积分完美统一。

### 牛顿-莱布尼茨公式（N-L 公式）

若 $F(x)$ 是 $f(x)$ 的任意一个原函数，则：

$$\int_a^b f(x)\,\mathrm{d}x = F(b) - F(a) = \left.F(x)\right|_a^b$$

**这是定积分计算的核心公式！**

**例题：** $\int_0^1 x^2\,\mathrm{d}x$

解：$F(x) = \frac{1}{3}x^3$，所以 $\int_0^1 x^2\,\mathrm{d}x = \frac{1}{3}(1)^3 - \frac{1}{3}(0)^3 = \frac{1}{3}$

---

## 6.4 定积分的换元法

$$\int_a^b f(x)\,\mathrm{d}x = \int_\alpha^\beta f[\varphi(t)]\varphi'(t)\,\mathrm{d}t$$

其中 $x = \varphi(t)$，$a = \varphi(\alpha)$，$b = \varphi(\beta)$。

>  注意！换元后上下限也要跟着变。

**例题：** $\int_0^{\frac{\pi}{2}} \cos^3 x\,\mathrm{d}x$

解：$\cos^3 x = \cos x(1 - \sin^2 x)$，令 $u = \sin x$，$\mathrm{d}u = \cos x\,\mathrm{d}x$

$x = 0 \to u = 0$，$x = \frac{\pi}{2} \to u = 1$

$\int_0^1 (1 - u^2)\,\mathrm{d}u = \left[u - \frac{1}{3}u^3\right]_0^1 = 1 - \frac{1}{3} = \frac{2}{3}$

---

## 6.5 定积分的分部积分法

$$\int_a^b u\,\mathrm{d}v = \left.uv\right|_a^b - \int_a^b v\,\mathrm{d}u$$

和不定的区别：带入了上下限。

**例题：** $\int_0^1 x e^x\,\mathrm{d}x$

解：$u = x$，$\mathrm{d}v = e^x\,\mathrm{d}x$，$\mathrm{d}u = \mathrm{d}x$，$v = e^x$

$\int_0^1 x e^x\,\mathrm{d}x = \left.x e^x\right|_0^1 - \int_0^1 e^x\,\mathrm{d}x$

$= (1 \cdot e - 0) - \left.e^x\right|_0^1 = e - (e - 1) = 1$

---

## 6.6 反常积分

### 无穷限反常积分

$$\int_a^{+\infty} f(x)\,\mathrm{d}x = \lim_{b \to +\infty} \int_a^b f(x)\,\mathrm{d}x$$

若极限存在，称反常积分**收敛**；否则**发散**。

**例题：** $\int_1^{+\infty} \frac{1}{x^2}\,\mathrm{d}x$

解：$\lim_{b \to +\infty} \int_1^b x^{-2}\,\mathrm{d}x = \lim_{b \to +\infty} \left[-\frac{1}{x}\right]_1^b = \lim_{b \to +\infty} \left(-\frac{1}{b} + 1\right) = 1$（收敛）

### 无界函数反常积分（瑕积分）

若 $f(x)$ 在 $x \to b^-$ 时无界：

$$\int_a^b f(x)\,\mathrm{d}x = \lim_{\varepsilon \to 0^+} \int_a^{b-\varepsilon} f(x)\,\mathrm{d}x$$

## 6.7 定积分的几何应用

### 平面图形的面积

**直角坐标下：**

$$A = \int_a^b |f(x) - g(x)|\,\mathrm{d}x$$

若 $f(x) \geq g(x)$ 在整个区间上成立，则 $A = \int_a^b [f(x) - g(x)]\,\mathrm{d}x$

**极坐标下：**

$$A = \frac{1}{2}\int_\alpha^\beta \rho^2(\theta)\,\mathrm{d}\theta$$

### 旋转体体积

绕 $x$ 轴旋转：
$$V = \pi \int_a^b [f(x)]^2\,\mathrm{d}x$$

绕 $y$ 轴旋转：
$$V = 2\pi \int_a^b x f(x)\,\mathrm{d}x$$

### 平面曲线弧长

$$s = \int_a^b \sqrt{1 + [f'(x)]^2}\,\mathrm{d}x$$

参数方程下：$s = \int_\alpha^\beta \sqrt{[x'(t)]^2 + [y'(t)]^2}\,\mathrm{d}t$

---

## 6.8 定积分的物理应用

| 应用 | 公式 |
|:---|:---|
| **变力做功** | $W = \int_a^b F(x)\,\mathrm{d}x$ |
| **液体压力** | $P = \rho g \int_a^b x \cdot w(x)\,\mathrm{d}x$ |
| **质心** | $\bar{x} = \frac{\int_a^b x f(x)\,\mathrm{d}x}{\int_a^b f(x)\,\mathrm{d}x}$ |

---

## 6.9 对称区间上的定积分

若 $f(x)$ 是奇函数（$f(-x) = -f(x)$）：
$$\int_{-a}^a f(x)\,\mathrm{d}x = 0$$

若 $f(x)$ 是偶函数（$f(-x) = f(x)$）：
$$\int_{-a}^a f(x)\,\mathrm{d}x = 2\int_0^a f(x)\,\mathrm{d}x$$

### 华里士公式（Wallis）

当 $n$ 为奇数：
$$\int_0^{\frac{\pi}{2}} \sin^n x\,\mathrm{d}x = \int_0^{\frac{\pi}{2}} \cos^n x\,\mathrm{d}x = \frac{(n-1)!!}{n!!}$$

当 $n$ 为偶数：
$$\int_0^{\frac{\pi}{2}} \sin^n x\,\mathrm{d}x = \int_0^{\frac{\pi}{2}} \cos^n x\,\mathrm{d}x = \frac{(n-1)!!}{n!!} \cdot \frac{\pi}{2}$$

其中 $!!$ 是双阶乘（隔一个乘一次）。
