# 第05章：不定积分

>  微分是「由 $f$ 求 $f'$」，积分是「由 $f'$ 反推 $f$」。积分比求导难，因为没有固定的机械套路 — 需要眼光和经验。

---

## 5.1 原函数与不定积分

### 原函数

若 $F'(x) = f(x)$，则称 $F(x)$ 是 $f(x)$ 的一个**原函数**。

**关键性质：** 原函数不唯一！若 $F(x)$ 是 $f(x)$ 的一个原函数，则 $F(x) + C$ 也是（$C$ 为任意常数）。

>  因为常数的导数是 0，加任何常数导数都不变。

### 不定积分

$f(x)$ 的所有原函数的集合称为不定积分，记作：

$$\int f(x)\,\mathrm{d}x = F(x) + C$$

其中：
- $\int$ — 积分号
- $f(x)$ — 被积函数
- $\mathrm{d}x$ — 积分变量
- $F(x)$ — 一个原函数
- $C$ — 积分常数（永远不要忘！）

---

## 5.2 基本积分公式

把求导公式倒过来就是积分公式：

| 积分公式 | 对应的导数 |
|:---|:---|
| $\int k\,\mathrm{d}x = kx + C$ | $(kx)' = k$ |
| $\int x^n\,\mathrm{d}x = \frac{x^{n+1}}{n+1} + C \quad (n \neq -1)$ | $\left(\frac{x^{n+1}}{n+1}\right)' = x^n$ |
| $\int \frac{1}{x}\,\mathrm{d}x = \ln|x| + C$ | $(\ln|x|)' = \frac{1}{x}$ |
| $\int e^x\,\mathrm{d}x = e^x + C$ | $(e^x)' = e^x$ |
| $\int a^x\,\mathrm{d}x = \frac{a^x}{\ln a} + C$ | |
| $\int \sin x\,\mathrm{d}x = -\cos x + C$ | $(-\cos x)' = \sin x$ |
| $\int \cos x\,\mathrm{d}x = \sin x + C$ | $(\sin x)' = \cos x$ |
| $\int \sec^2 x\,\mathrm{d}x = \tan x + C$ | |
| $\int \csc^2 x\,\mathrm{d}x = -\cot x + C$ | |
| $\int \sec x \tan x\,\mathrm{d}x = \sec x + C$ | |
| $\int \frac{1}{\sqrt{1-x^2}}\,\mathrm{d}x = \arcsin x + C$ | |
| $\int \frac{1}{1+x^2}\,\mathrm{d}x = \arctan x + C$ | |

>  重点记：幂函数积分式、$\frac{1}{x}$、$e^x$、$\sin x$、$\cos x$。

---

## 5.3 不定积分的线性性质

$$\int [f(x) \pm g(x)]\,\mathrm{d}x = \int f(x)\,\mathrm{d}x \pm \int g(x)\,\mathrm{d}x$$
$$\int k f(x)\,\mathrm{d}x = k \int f(x)\,\mathrm{d}x \quad (k \neq 0)$$

---

## 5.4 换元积分法（第一类）

也叫**凑微分法**。核心思想：把复杂的被积函数「凑成」基本公式的形式。

$$\int f[\varphi(x)]\varphi'(x)\,\mathrm{d}x = \int f(u)\,\mathrm{d}u \quad (\text{令 } u = \varphi(x))$$

### 常见凑微分形式

| 积分形式 | 处理方式 |
|:---|:---|
| $\int f(ax+b)\,\mathrm{d}x$ | 令 $u = ax+b$，$\mathrm{d}x = \frac{1}{a}\mathrm{d}u$ |
| $\int f(\sin x)\cos x\,\mathrm{d}x$ | 令 $u = \sin x$，$\mathrm{d}u = \cos x\,\mathrm{d}x$ |
| $\int f(\cos x)\sin x\,\mathrm{d}x$ | 令 $u = \cos x$，$\mathrm{d}u = -\sin x\,\mathrm{d}x$ |
| $\int f(\ln x)\frac{1}{x}\,\mathrm{d}x$ | 令 $u = \ln x$，$\mathrm{d}u = \frac{1}{x}\mathrm{d}x$ |
| $\int f(e^x)e^x\,\mathrm{d}x$ | 令 $u = e^x$，$\mathrm{d}u = e^x\,\mathrm{d}x$ |

**例题：** $\int \sin(3x+2)\,\mathrm{d}x$

解：令 $u = 3x+2$，$\mathrm{d}u = 3\,\mathrm{d}x$，$\mathrm{d}x = \frac{1}{3}\mathrm{d}u$

$\int \sin u \cdot \frac{1}{3}\,\mathrm{d}u = -\frac{1}{3}\cos u + C = -\frac{1}{3}\cos(3x+2) + C$

**例题：** $\int \frac{\ln x}{x}\,\mathrm{d}x$

解：令 $u = \ln x$，$\mathrm{d}u = \frac{1}{x}\,\mathrm{d}x$

$\int u\,\mathrm{d}u = \frac{1}{2}u^2 + C = \frac{1}{2}(\ln x)^2 + C$

---

## 5.5 第二类换元法

令 $x = \psi(t)$，则 $\mathrm{d}x = \psi'(t)\,\mathrm{d}t$。

**常见类型：**

| 被积函数形式 | 换元 |
|:---|:---|
| $\sqrt{a^2 - x^2}$ | $x = a\sin t$ |
| $\sqrt{a^2 + x^2}$ | $x = a\tan t$ |
| $\sqrt{x^2 - a^2}$ | $x = a\sec t$ |

**例题：** $\int \sqrt{a^2 - x^2}\,\mathrm{d}x$

解：令 $x = a\sin t$，$\mathrm{d}x = a\cos t\,\mathrm{d}t$

$\int \sqrt{a^2 - a^2\sin^2 t} \cdot a\cos t\,\mathrm{d}t = a^2\int \cos^2 t\,\mathrm{d}t$

用 $\cos^2 t = \frac{1+\cos 2t}{2}$：
$= \frac{a^2}{2}\int (1 + \cos 2t)\,\mathrm{d}t = \frac{a^2}{2}\left(t + \frac{1}{2}\sin 2t\right) + C$

换回 $x$：$t = \arcsin\frac{x}{a}$，$\sin 2t = 2\sin t\cos t = \frac{2x}{a} \cdot \frac{\sqrt{a^2-x^2}}{a}$

$= \frac{a^2}{2}\arcsin\frac{x}{a} + \frac{x}{2}\sqrt{a^2-x^2} + C$

---

## 5.6 分部积分法

由乘积的求导法则倒推：

$$\int u\,\mathrm{d}v = uv - \int v\,\mathrm{d}u$$

**口诀：** 「反、对、幂、三、指」—— $u$ 的选取优先级。

| 优先级 | 函数类型 | 选作 $u$ 的原因 |
|:---|:---|:---|
| 1 | 反三角函数 | 求导后变有理函数 |
| 2 | 对数函数 | 求导后变 $\frac{1}{x}$ |
| 3 | 幂函数 | 求导后降次 |
| 4 | 三角函数 | 求导后在 sin/cos 间切换 |
| 5 | 指数函数 | 求导后还是指数函数 |

**例题：** $\int x e^x\,\mathrm{d}x$

解：幂函数（级别 3）优先于指数（级别 5），选 $u = x$，$\mathrm{d}v = e^x\,\mathrm{d}x$

则 $\mathrm{d}u = \mathrm{d}x$，$v = e^x$

$\int x e^x\,\mathrm{d}x = x e^x - \int e^x\,\mathrm{d}x = x e^x - e^x + C = e^x(x-1) + C$

**例题：** $\int \ln x\,\mathrm{d}x$

解：$\ln x$ 算对数函数（级别 2），$u = \ln x$，$\mathrm{d}v = \mathrm{d}x$

$\mathrm{d}u = \frac{1}{x}\,\mathrm{d}x$，$v = x$

$\int \ln x\,\mathrm{d}x = x\ln x - \int x \cdot \frac{1}{x}\,\mathrm{d}x = x\ln x - x + C$

>  积分练的不是公式，是**感觉**。哪个方法能拆干净，只能多做题培养。

---

## 5.7 有理函数的积分

对于 $\frac{P(x)}{Q(x)}$（多项式之比），步骤：
1. 若分子次数 $\geq$ 分母，先做多项式除法
2. 将分母因式分解
3. 拆成**部分分式**之和
4. 逐项积分

**部分分式常见模式：**
$$\frac{1}{(x-a)(x-b)} = \frac{A}{x-a} + \frac{B}{x-b}$$
