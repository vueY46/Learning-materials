## 1. 封装 (Encapsulation)

### 1.1 什么是封装

把数据（属性）和操作（方法）打包在类内部，隐藏实现细节，只暴露必要接口。

**现实类比：** 你用手机打电话，不需要知道内部电路怎么工作的。

### 1.2 Python 的私有成员

用双下划线 `__` 前缀声明私有：

```python
class CellPhone:
    def __init__(self, brand, voltage):
        self.brand = brand
        self.__voltage = voltage      # 私有属性
    
    def __power_saving_mode(self):    # 私有方法
        print("启动省电模式...")
    
    def phoneCall(self):
        if self.__voltage <= 20:
            self.__power_saving_mode()  # 内部可以调用私有方法
            print("使用 4G 通话")
        else:
            print("使用 5G 通话")

phone = CellPhone("xiaomi", 78)
phone.phoneCall()                      # ✅ 公开方法可以调用
# phone.__voltage                      # ❌ 外部不能直接访问
# phone.__power_saving_mode()          # ❌ 外部不能调用
```

### 1.3 封装原则

| 对外公开 | 对内隐藏 |
|:---|:---|
| 用户需要调用的方法 | 内部实现细节 |
| 如：`call_by_5g()`, `camera()` | 如：`__is_5g_enable`, `__check_5g()` |

## 2. 继承 (Inheritance)

### 2.1 为什么需要继承

当多个类有重复的属性和方法时，提取公共部分到父类，减少代码冗余。

```
Person（父类）
  ├── name, age, gender
  └── speak()
       │
  ┌────┴────┬──────────┐
Student    Teacher    Driver
  id        salary     driveTime
  study()   teach()    drive()
```

### 2.2 单继承语法

```python
class Person:
    def __init__(self, name, age, gender):
        self.name = name
        self.age = age
        self.gender = gender
    
    def eat(self):
        print(f"{self.name} 在吃饭")

class Teacher(Person):                     # 继承 Person
    def __init__(self, name, age, gender, teach_time):
        super().__init__(name, age, gender)  # 调用父类构造方法
        self.teach_time = teach_time
    
    def teach(self):
        print(f"{self.name} 老师在上课")

t = Teacher("李老师", 35, "男", 10)
t.eat()     # 继承自父类
t.teach()   # 自己的方法
```

>  **`super()`**：调用父类的方法，常用于子类构造方法中初始化父类属性。

### 2.3 多继承

Python 支持一个类继承多个父类：

```python
class Phone:
    def call(self):
        print("打电话")

class NFC:
    def read_card(self):
        print("读卡")

class XiaoMi(Phone, NFC):   # 继承两个父类
    pass

mi = XiaoMi()
mi.call()       # 来自 Phone
mi.read_card()  # 来自 NFC
```

**注意：** 多个父类有同名方法时，按继承顺序（从左到右）优先。

## 3. 复写 (Override)

子类对父类的方法「不满意」，重新定义同名方法：

```python
class Animal:
    def speak(self):
        print("动物在叫...")

class Cat(Animal):
    def speak(self):                     # 复写父类方法
        print("喵喵喵~")

class Dog(Animal):
    def speak(self):                     # 复写父类方法
        print("汪汪汪!")

cat = Cat()
cat.speak()  # 喵喵喵~ — 调用的是子类复写后的版本
```

**调用被复写的父类方法：**

```python
class Cat(Animal):
    def speak(self):
        super().speak()        # 方式1：super() 调用父类方法
        # Animal.speak(self)   # 方式2：父类名.方法(self)
        print("喵喵喵~")
```

## 4. 多态 (Polymorphism)

### 4.1 概念

**同一个方法，不同的对象调用，产生不同的行为。**

```python
class Animal:
    def speak(self):
        pass           # 父类只定义规范

class Cat(Animal):
    def speak(self):
        print("喵~")

class Dog(Animal):
    def speak(self):
        print("汪~")

# 多态体现：同一个函数，传入不同对象，得到不同结果
def make_sound(animal: Animal):
    animal.speak()

make_sound(Cat())   # 喵~
make_sound(Dog())   # 汪~
```

**核心：** 以父类类型声明参数，实际传入子类对象工作。

## 5. 抽象类 (Abstract Class / 接口)

### 5.1 概念

抽象类 = 只定义方法签名，不实现（用 `pass`）。子类必须实现这些方法。

```python
from abc import ABC, abstractmethod

class USB(ABC):                    # 抽象类 = 接口标准
    @abstractmethod
    def turn_on(self):
        pass
    
    @abstractmethod
    def turn_off(self):
        pass

class Keyboard(USB):
    def turn_on(self):
        print("键盘启动")
    
    def turn_off(self):
        print("键盘关闭")

class Mouse(USB):
    def turn_on(self):
        print("鼠标启动")
    
    def turn_off(self):
        print("鼠标关闭")
```

### 5.2 为什么用抽象类

就像 USB 标准：定义了插槽规范，不管哪个厂家的设备，只要符合规范就能用。

>  **设计思路：** 父类定标准 → 子类各实现 → 多态来调用。

## 6. 综合案例：计算机组装

```python
class Computer:
    def __init__(self):
        self.devices_list = []
    
    def turn_on(self):
        for device in self.devices_list:
            device.turn_on()
        print("------- 计算机启动 --------")
    
    def turn_off(self):
        for device in self.devices_list:
            device.turn_off()
        print("------- 计算机关闭 --------")

# 组装
c = Computer()
c.devices_list.append(Keyboard())
c.devices_list.append(Mouse())
c.devices_list.append(Micphone())
c.turn_on()
c.turn_off()
```
