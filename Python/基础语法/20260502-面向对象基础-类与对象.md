## 1. 面向对象 vs 面向过程

| 编程范式 | 核心思想 | 例子 |
|:---|:---|:---|
| **面向过程 (POP)** | 把问题拆成步骤，依次调用函数 | 学生信息用散装变量存，混乱 |
| **面向对象 (OOP)** | 把数据和操作打包成对象，通过对象交互 | 设计「学生类」，每个学生是一个对象 |

**通俗理解：**
- 过程式 = 一人发一张白纸随便写 → 内容混乱
- 对象式 = 打印登记表让学生填 → 整洁统一

## 2. 类和对象

### 2.1 概念

- **类 (Class)**：同一类事物的抽象描述，是「设计图 / 模板」
- **对象 (Object)**：类的具体实例，是「按设计图造出来的真实个体」

```python
# 类 = 设计图
class Student:
    pass

# 对象 = 按图造出来的实例
st1 = Student()
```

### 2.2 类的定义要素

一个类包含：
- **属性 (状态)**：对象拥有的数据，如姓名、年龄
- **方法 (行为)**：对象能做的事，如学习、吃饭

```python
class Car:
    # 属性
    brand = "保时捷"
    color = "灰色"
    
    # 方法
    def drive(self):
        print("行驶中...")
    
    def brake(self):
        print("刹车!")
```

## 3. 类属性 vs 实例属性

| 对比 | 类属性 | 实例属性 |
|:---|:---|:---|
| 定义位置 | 类内部、方法外部 | 方法内部 (用 `self.xxx`) |
| 归属 | 属于类，所有对象共享 | 属于具体对象，各自独立 |
| 访问 | 类名 / 对象都能读 | 只能通过对象访问 |
| 修改 | 只能通过类名修改 | 通过对象修改 |

```python
class Car:
    wheels = 4          # 类属性：所有车默认 4 个轮子
    
    def __init__(self, color):
        self.color = color  # 实例属性：每辆车颜色不同

c1 = Car("红色")
c2 = Car("蓝色")

print(Car.wheels)   # 4 — 通过类访问
print(c1.wheels)    # 4 — 通过对象访问

Car.wheels = 3      # 通过类修改 → 所有实例都变
# c1.wheels = 5     # 通过对象赋值 → 只在 c1 上新建了实例属性，不影响类属性！
```

>  重要：对象 `obj.attr = val` 不会修改类属性，而是给这个对象新增了一个同名的实例属性。

## 4. 实例属性操作

### 4.1 动态添加

```python
class Student:
    pass

st1 = Student()
st1.age = 18           # 直接动态添加
st1.region = "河北省石家庄市"
```

### 4.2 通过构造方法 `__init__()` 添加

```python
class Student:
    def __init__(self, name, age):
        self.name = name    # 实例属性
        self.age = age

st1 = Student("张三", 20)
```

### 4.3 修改和删除

```python
st1.age = 22           # 修改
del st1.age            # 删除

# 查看所有实例属性
print(st1.__dict__)    # {'name': '张三'}
```

## 5. 方法分类

### 5.1 实例方法

```python
class Car:
    def drive(self):          # self 代表调用该方法的对象本身
        print("我是实例方法")

car = Car()
car.drive()                  # ✅ 通过对象调用
# Car.drive()                # ❌ 不能直接通过类调用（缺少 self 参数）
```

### 5.2 类方法

```python
class Car:
    wheels = 4
    
    @classmethod
    def stop(cls):            # cls 代表类本身
        print(cls.wheels)     # 通过 cls 访问类属性
        cls.wheels = 3        # 通过 cls 修改类属性

car = Car()
car.stop()    # ✅ 对象调用
Car.stop()    # ✅ 类调用
```

### 5.3 静态方法

```python
class Car:
    wheels = 4
    
    @staticmethod
    def test():
        print(f"类属性: {Car.wheels}")  # 用类名访问

car = Car()
car.test()    # ✅ 对象调用
Car.test()    # ✅ 类调用
```

### 三种方法对比

| 类型 | 装饰器 | 第一个参数 | 能否访问实例属性 | 能否访问类属性 |
|:---|:---|:---|:---|:---|
| 实例方法 | 无 | `self` | ✅ | ✅ |
| 类方法 | `@classmethod` | `cls` | ❌ | ✅ |
| 静态方法 | `@staticmethod` | 无 | ❌ | 通过类名可以 |
